## Original work and portfolio additions

The native model is the user's supplied individual coursework artifact. Its metadata establishes the Signavio exporter; it does not establish a grade, certification, new import result or production deployment.

The English/Traditional Chinese portfolio text, improvement case, measurement plan, inspection script and preview generation were added for this repository with AI assistance. Improvements are proposed extensions, not features secretly incorporated into the original AS-IS model.

The source model's SHA-256 and element inventory are recorded in [model-inventory.json](model-inventory.json). Regenerate them with `python3 scripts/inspect_model.py --write --check` from the repository root.
